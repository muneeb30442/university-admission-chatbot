================================================================================
THREE RESPONSE GENERATION METHODS
================================================================================

1️⃣  RULE-BASED KEYWORD MATCHING
   - Speed: 1-2ms
   - Method: Keyword counting
   - File: modules/rule_based.py
   - Best for: Fast responses, exact matches

2️⃣  INTENT CLASSIFICATION (ML-BASED)
   - Speed: 5-10ms
   - Method: TF-IDF + Naive Bayes
   - File: modules/intent_classifier.py
   - Best for: Varied patterns, accurate classification

3️⃣  NLP SIMILARITY MATCHING
   - Speed: 10-20ms
   - Method: TF-IDF + Cosine Similarity
   - File: modules/nlp_similarity.py
   - Best for: Semantic understanding, flexible matching

4️⃣  ENSEMBLE METHOD (RECOMMENDED)
   - Speed: 25-40ms
   - Method: Weighted average of all three
   - Default Weights: Rule (20%), Classifier (40%), Similarity (40%)
   - Best for: Overall accuracy, production use

================================================================================
CUSTOMIZATION GUIDE
================================================================================

To Add New Q&A:
   1. Edit knowledge_base.json
      Add a new entry in the appropriate section
   2. Edit intents.json
      Add patterns that should trigger this Q&A
   3. Restart app.py
      Changes take effect immediately

To Add Test Queries:
   1. Edit test_queries.json
   2. Add a new object with query, expected_intent, category
   3. Run test_chatbot.py to evaluate

To Adjust Method Weights:
   1. Edit chatbot.py (line ~60)
   2. Change self.method_weights values
   3. Must sum to 1.0
   4. Restart app.py

TROUBLESHOOTING
================================================================================

Module Not Found Error:
   Solution: Ensure you're in chatbot directory and installed requirements
   Command: pip install -r requirements.txt

Port Already in Use:
   Solution: Use different port
   Command: export FLASK_PORT=8080 && python app.py

Low Accuracy:
   Solution: Add more patterns to intents.json
   Or: Adjust method weights toward better-performing methods

Missing Knowledge:
   Solution: Add Q&A pairs to knowledge_base.json
   Then: Add corresponding intent pattern to intents.json
