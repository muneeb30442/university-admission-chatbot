This guide shows you how to test the new out-of-context detection feature.

================================================================================
WHAT IS OUT-OF-CONTEXT DETECTION?
================================================================================

When users ask questions unrelated to university admissions, the chatbot now
automatically detects this and responds with a polite apology message instead
of trying to answer.

Examples:
- Query: "Tell me a joke" → Apology message
- Query: "What's the weather?" → Apology message
- Query: "What is the application deadline?" → Normal admission answer

================================================================================
HOW TO TEST
================================================================================

TEST #1: IN-CONTEXT QUERY (Should Process Normally)
-------------------------------------------------------
Query:  "What are the application requirements?"
Expected Result:
  ✓ Method: Should be one of 'rule_based', 'intent_classifier', 'nlp_similarity', or 'ensemble'
  ✓ is_out_of_context: false
  ✓ Response: Actual admission information
  ✓ Confidence: > 0.3

Test Status: PASS if all above match, FAIL if any don't match

  ✓ Confidence: 1.0

================================================================================
HOW TO READ THE RESPONSE
================================================================================

Response Format:
{
    'user_input': 'original query',
    'final_response': 'chatbot response',
    'confidence': 0.0-1.0,
    'method': 'detection method used',
    'is_out_of_context': true/false,
    'out_of_context_reason': 'reason if out-of-context',
    'timestamp': 'when query was processed'
}

Key Fields to Check:

1. is_out_of_context (true/false)
   - TRUE = Query was detected as out-of-context
   - FALSE = Query is about admissions

2. method (string)
   - 'out_of_context_detection' = Out-of-context query detected
   - 'rule_based', 'intent_classifier', 'nlp_similarity', 'ensemble' = Normal processing

3. out_of_context_reason (when is_out_of_context = true)
   - 'out_of_context_keywords' = More off-topic than admission keywords
   - 'no_relevant_keywords' = No relevant keywords found
   - 'low_relevance_score' = Below relevance threshold
   - None = Not out-of-context (in-context query)

4. confidence (0.0 to 1.0)
   - 1.0 = Certain (out-of-context detection)
   - 0.3-0.9 = Normal response confidence
   - < 0.3 = Uncertain

================================================================================
CONFIGURATION FOR TESTING
================================================================================

Want to change how the detector works? Edit these files:

1. SENSITIVITY (in modules/out_of_context_detector.py):
   
   Line: confidence_threshold: float = 0.3
   
   Change 0.3 to:
   - 0.1 = More lenient (fewer detected as out-of-context)
   - 0.3 = Default (balanced)
   - 0.5 = Stricter (more detected as out-of-context)


2. APOLOGY MESSAGE (in knowledge_base.json):
   
   Change the message in:
   "messages": {
       "out_of_context_apology": "YOUR CUSTOM MESSAGE HERE"
   }


3. ADD CUSTOM KEYWORDS (in modules/out_of_context_detector.py):
   
   self.admission_keywords = {
       'existing...',
       'your_new_keyword'  # Add here
   }
   
   self.out_of_context_keywords = {
       'existing...',
       'your_new_keyword'  # Add here
   }

================================================================================
PERFORMANCE NOTES
================================================================================

- Out-of-context detection is FAST (~2-5ms per query)
- It runs BEFORE the three response methods
- Out-of-context queries skip all three methods (saves processing time)
- No external API calls or network latency
- Logging is enabled for all detections

When testing, you should notice out-of-context queries respond faster than
normal admission queries (because they skip processing).


================================================================================
TROUBLESHOOTING
================================================================================

Problem: Out-of-context query was not detected as out-of-context
Solution:
  1. Check if the query contains admission keywords
  2. If yes, increase sensitivity (lower threshold to 0.1)
  3. Check if keywords need to be added to the lists
  4. Review the out_of_context_reason in response

Problem: In-context query was incorrectly detected as out-of-context
Solution:
  1. Check the out_of_context_reason field
  2. Add the missing admission keyword to the list
  3. Lower sensitivity (increase threshold to 0.5)

Problem: Apology message not appearing
Solution:
  1. Check that out-of-context_apology message is in knowledge_base.json
  2. Restart the chatbot application
  3. Check logs for errors in modules/out_of_context_detector.py

Problem: Response method shows something other than expected
Solution:
  1. Check is_out_of_context flag (true/false)
  2. Check out_of_context_reason for explanation
  3. Review configuration settings
