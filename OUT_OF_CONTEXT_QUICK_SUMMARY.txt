HOW IT WORKS
================================================================================

When user submits a query:

  1. Check for admission-related keywords (deadline, GPA, tuition, etc.)
  2. Check for out-of-context keywords (weather, joke, recipe, etc.)
  3. Calculate relevance score (admission keywords / total keywords)
  4. If relevance < 30% → Return apology message
  5. If relevance ≥ 30% → Process normally through 3 methods

API RESPONSE FORMAT
================================================================================

IN-CONTEXT RESPONSE:
{
    'method': 'ensemble',
    'is_out_of_context': false,
    'final_response': 'Actual admission information...',
    'confidence': 0.85
}

OUT-OF-CONTEXT RESPONSE:
{
    'method': 'out_of_context_detection',
    'is_out_of_context': true,
    'out_of_context_reason': 'out_of_context_keywords',
    'final_response': 'I appreciate your question, but I\'m specifically...',
    'confidence': 1.0
}


DETECTION REASONS
================================================================================

When out-of-context is detected, the response includes the reason:

- out_of_context_keywords    → More off-topic than admission keywords
- no_relevant_keywords       → No relevant keywords found
- low_relevance_score        → Relevance score below 30% threshold

CUSTOMIZATION
================================================================================

1. CHANGE APOLOGY MESSAGE
   
   Edit: chatbot/knowledge_base.json
   
   Find: "out_of_context_apology": "..."
   Change to your custom message


2. ADJUST SENSITIVITY
   
   Edit: chatbot/modules/out_of_context_detector.py
   
   Find: confidence_threshold: float = 0.3
   
   Change to:
   - 0.1  = More lenient (fewer detected as out-of-context)
   - 0.3  = Default (balanced)
   - 0.5  = Stricter (more detected as out-of-context)


3. ADD CUSTOM KEYWORDS
   
   Edit: chatbot/modules/out_of_context_detector.py
   
   Find: self.admission_keywords = { ... }
   Add:  'your_new_keyword'
